# Glossary

- **Grammar checker** — software that flags grammar, spelling, and punctuation errors and suggests corrections (LanguageTool, Harper).
- **Prose linter** — a rule-based style checker for text files, usually run from the command line or in CI (Vale, proselint, alex, write-good). Checks style-guide rules, not deep grammar.
- **Readability score** — a formula estimating the education level needed to read a text (Flesch-Kincaid, Gunning Fog, SMOG). A proxy for clarity, not a quality grade: a low score is not automatically better writing.
- **Free tier vs free trial** — a free tier is a permanent, capped plan you can use indefinitely. A trial is full access that expires. This list includes free tiers and fully free tools only; trials are excluded.
- **Freemium** — a product with a permanent free tier and paid tiers above it. Most entries here are freemium; the catalog states what the free tier caps.
- **Paraphrasing / rewriting tool** — AI that restates a sentence in different words or tones (QuillBot Paraphraser, Wordtune, DeepL Write). Related to grammar checking, but it changes your text rather than correcting it — review every rewrite.
- **Plagiarism checker** — compares text against a corpus (web pages, papers) and reports matching passages (Quetext, PaperRater). A match is not automatically plagiarism; quotes and references match legitimately.
- **Style guide (product sense)** — a set of enforced wording rules for a team or publication (e.g., AMA style for medical journals). Tools like Trinka and Sapling check against named guides.
- **Self-hosted** — you run the software on your own computer or server. Free of subscription and per-check limits, at the cost of your own setup and updates.
- **OSS / open source** — source code available under an open license (MIT, Apache-2.0, GPL, LGPL). The catalog's `open_source` flag; note that some tools pair an open core with proprietary cloud features (LanguageTool).
