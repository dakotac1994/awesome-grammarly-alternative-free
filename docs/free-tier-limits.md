# Free-tier limits, honestly

What each free tier actually lets you do, as of 2026-10-04. Limits change often; the vendor's pricing page (linked from the catalog entry) is the source of truth. "Unlimited" below means the vendor does not publish a cap for that feature on the free tier.

| Tool | Free-tier cap that matters | What the paid tier adds |
|---|---|---|
| LanguageTool | Basic grammar/spelling/style only; shorter text fields; limited AI paraphrases/day | Advanced style rules, picky mode, larger texts, unlimited paraphrasing |
| QuillBot | Paraphrase 125 words, 2 modes; basic grammar fixes | Unlimited paraphrase, all modes, advanced grammar recommendations, tone insights |
| ProWritingAid | 500 words per check (web + extension); daily report/rephrase quotas | Unlimited words and reports, all integrations, plagiarism credits |
| Ginger | Basic grammar/spell check | Unlimited checks, sentence rephrasing, translation features |
| Sapling | Basic suggestions for individuals | Team snippets, style guides, analytics, CRM integrations |
| Linguix | Basic grammar/spelling/style checks | Paraphrasing quotas, team style guides, productivity analytics |
| Scribens | Free web checker (ads) | Ad-free, higher limits, Word add-in features |
| Outwrite | Basic spelling/grammar | Paraphrasing, eloquence suggestions, plagiarism checker |
| Wordvice AI | Light proofreading mode; monthly word cap | All proofreading modes, higher word limits, full AI tool suite |
| DeepL Write | Basic Write suggestions (language-dependent) | Write Pro: unlimited suggestions, enterprise security |
| Wordtune | Daily rewrite quota | Higher/unlimited rewrites, more tones and features |
| Hemingway Editor | Full web editor free; no saving/export in web version | Desktop app: offline, save/export, publish. Plus: AI rewrites |
| Trinka | Monthly grammar-check credits | More credits, journal style guides, consistency checks |
| Writefull | Limited revise/paraphrase in Word/Overleaf | Unlimited revising, full academic phrasebank features |
| Paperpal | Limited language suggestions | Unlimited suggestions, submission-readiness and plagiarism checks |
| Quetext | Limited plagiarism words/month | Higher limits, detailed reports, grammar suite |
| Microsoft Editor | Basic spelling/grammar in Edge/Chrome | Clarity/conciseness/vocabulary refinements with Microsoft 365 |
| Google Docs suggestions | Included with Google account | Workspace plans add admin/team features, not deeper grammar |

## When paying is actually worth it

- You write **professionally every day** and the advanced style rules (not the basic fixes) save real editing time.
- You need **team style guides** enforced across writers (Sapling, Linguix, LanguageTool Teams).
- You need **plagiarism checking at volume** — free tiers ration it hard everywhere.

For occasional writing, every paid tier on this page is a convenience, not a necessity. The free stack in [choosing-a-checker](choosing-a-checker.md) covers the core job.
